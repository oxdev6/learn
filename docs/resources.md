# 🧠 LearnSecure Resource Hub

Expand your DeFi knowledge beyond the modules. These handpicked resources are designed to help you stay safe, smart, and up-to-date in the evolving world of Web3.

---

## 🔧 Security & Analysis Tools

- [**Revoke.cash**](https://revoke.cash) — Revoke token approvals and check dApp permissions.
- [**Tenderly**](https://tenderly.co) — Simulate transactions before you sign.
- [**Scam Sniffer**](https://scamsniffer.io) — Browser extension for phishing detection.
- [**DeFi Saver**](https://defisaver.com) — Automate liquidation protection and leverage.
